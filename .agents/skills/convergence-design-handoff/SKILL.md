Read DESIGN.md, docs/agents/design-library-workflow.md and docs/agents/design-handoff.md. Follow the Handoff and Reconcile after implementation sections.

Use selected final frames only. Link inspectable component anatomy, state examples and a working prototype. Specify motion and reduced motion in words as well as animation. Verify text, clipping, density and navigation; identify illustrative data and typography substitutions. Carry numbered walkthrough steps with expected outcomes into the Linear brief for Fable's implementing issue.

Require an editable full-app composition and exact source component links. Do not hand off a screenshot-backed placement study as a design. Include structural audit evidence and the named build used for visual comparison; list any unverified states. Prototype only the interactions needed by the brief, and distinguish simulated behavior from real data or execution.

Freeze dependencies, not merely frame names: nested instances, shared styles and variables can otherwise change history. Keep subsequent exploration separate. Record implementing-seat access as confirmed only when there is evidence. Do not dispatch, merge or release through this skill. At review, name the actual build and exact reference; report drift without silently rewriting the frozen agreement.

Use the shared workflow’s Present component capabilities standard for final references. Show the selected component’s meaningful states and optional elements visibly, with plain-language titles and explanations, so humans and implementing agents can understand its capabilities without inspecting hidden settings.
